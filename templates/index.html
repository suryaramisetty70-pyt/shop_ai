📊 7-Module Production Architecture Summary

Complete system breakdown for project evaluation and viva demonstration.

System Architecture Highlights

1. Multi-Platform Price Aggregation Engine — Real-time price, rating, and review count comparison across Amazon, Flipkart, and Croma with calculated savings amount and 1-100 Bargain Score.

2. PyTorch Neural Collaborative Filtering (NCF) — 16-dimensional embedding layers mapping user interactions into latent preference vectors for personalized Top-K ranking.

3. Price Trend Regression & Buy Signals — 30-day price trend analysis predicting future price movement with automated BUY NOW or WAIT signals.

4. NLP Sentiment & Review Summarization — Natural language review parsing extracting positive and negative features (Pros & Cons) across customer feedback.

5. Computer Vision Visual Search — 64-dimensional visual feature vector similarity matching with Cosine Similarity ranking.

6. Agentic RAG Conversational AI Assistant — LLM-grounded conversational assistant with Groq LLaMA-3.1 and Google Gemini API integration.

7. Zero Cost & Production Ready — 100% free open-source stack (Python, Flask, PyTorch, Scikit-Learn/NumPy, Vanilla JS) running on Port 5050 and cloud deployment ready for Vercel/Render.
